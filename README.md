## 自动备份（已配好，不用管）

**每天凌晨 2:00 自动把数据同步到 GitHub。**

- 定时任务名：`FitTrackerDailyBackup`
- 执行内容：`_backup.js` —— 从浏览器读最新打卡数据 → 写进仓库 `data.json` → 顺便同步代码
- 查看状态：`powershell -ExecutionPolicy Bypass -File _task.ps1 status`
- 立即跑一次：`powershell -ExecutionPolicy Bypass -File _task.ps1 run`
- 卸载：管理员运行 `_task.ps1 remove`

日志写在 `backup.log`。

**电脑关机/睡眠时**：任务设了「错过后补跑」（StartWhenAvailable），开机后会补上。

**App 里也有即时备份**：设置 → 自动备份 → 填 GitHub Token 和仓库名，
之后**每次打卡都会自动上传**（延迟 20 秒防抖）。

## 目标锁定

**目标一旦设定、计划开始，就不能改了**，设置页里的目标字段会变灰。

为什么锁：中途改目标就是改考核标准 —— 减不动了就把目标调低，这个计划就没意义了。

**达成主目标后自动解锁**，并按新目标重新排方案。
想重新开始，把「开始日期」改到未来即可（那是准备阶段，允许改）。
